# Estimación del Nivel de Obesidad Basado en Hábitos Alimenticios y Condición Física
Este proyecto desarrolla una solución de clasificación multiclase mediante técnicas de Machine Learning para predecir el nivel de obesidad de una persona a partir de sus hábitos alimenticios, actividad física y condición general. Se trabajaron seis modelos: Regresión Logística, K-Nearest Neighbors, Random Forest, Gradient Boosting, Redes Neuronales y Máquina de Vectores de Soporte, evaluados sobre cuatro subconjuntos de características (completo, filtrado, PCA y LDA).

# Dataset:
El dataset utilizado es Estimation of Obesity Levels Based on Eating Habits and Physical Condition. Contiene 2,111 registros con 16 variables independientes y una variable objetivo con 7 clases de nivel de obesidad.
